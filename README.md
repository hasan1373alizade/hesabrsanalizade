# سایت خدمات حسابداری و حسابرسی

## فایل‌ها
- `index.html`: صفحه اصلی سایت
- `style.css`: طراحی واکنش‌گرا برای موبایل و رایانه
- `script.js`: نمایش خودکار سال جاری

## انتشار رایگان با GitHub Pages
1. فایل ZIP را از حالت فشرده خارج کنید.
2. وارد مخزن GitHub خود شوید.
3. روی `Add file` و سپس `Upload files` بزنید.
4. فایل‌های `index.html`، `style.css`، `script.js` و `README.md` را بارگذاری کنید (خود فایل ZIP را به‌تنهایی بارگذاری نکنید).
5. پایین صفحه روی `Commit changes` بزنید.
6. به `Settings` → `Pages` بروید.
7. در بخش Build and deployment، گزینه `Deploy from a branch` را انتخاب کنید.
8. Branch را روی `main` و پوشه را روی `/(root)` قرار دهید و `Save` را بزنید.
9. چند دقیقه صبر کنید؛ نشانی سایت در همان صفحه Pages نمایش داده می‌شود.

## پیش از انتشار
شماره تماس و محدوده فعالیت طبق اطلاعات ارائه‌شده وارد شده‌اند. متن خدمات را بررسی کنید و فقط خدماتی را نگه دارید که واقعاً ارائه می‌کنید. سایت از فونت آنلاین استفاده می‌کند؛ بدون اینترنت نیز با فونت جایگزین نمایش داده می‌شود.
